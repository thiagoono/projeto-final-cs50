A página será um todo-list inteligente.

Primeiro haverá uma tela de login com uma maneira de criar uma nova conta.
Na criação da conta deve ser possível registrar o país
DONE (falta só criar o banco de dados para finalizar)

O index.html terá todas as tarefas do dia, contendo uma linha do tempo.
Além disso, haverá um nav onde será possível acessar todas as outras abas da página.

Terá uma aba para registrar uma nova tarefa, onde será possível utilizar o chatGPT para registrar de forma mais rápida, e com uma confirmação, para garantir que o chatGPT entendeu corretamente. Além disso, o chatGPT tambem deverá informar se algum dia deve ser excluído por ser feriado ou fim de semana (por isso é tão importante a confirmação).
Além disso, o usuário deverá informar a duração, caso contrário o chatGPT deverá chutar uma duração que ele ache condizente
Após a resposta do chatGPT, o sistema deverá verificar se há alguma tarefa no mesmo horário

Terá uma aba para mudar o seu perfil, sendo possível mudar o nome de usuário e a senha.
Além disso também será possível mudar o país (influenciará por conta dos feriados)

Terá uma aba para criar tarefas que se repetirão. Neste caso, deverá ser feito um formulário mesmo, ao invés de utilizar a inteligência artificial, contendo nome, data, duração, a cada quanto tempo se repetirá e se deverá ser excluídos nos feriados (mostrar todos e permitir que o usuário escolha de quais feriados a tarefa será excluída)

Além disso, haverá uma página onde será possível ver todas as tarefas criadas em uma linha do tempo e editá-las, além disso, haverá sugestões do chatGPT caso ele verifique se tem algum dia com muitas tarefas (mostrar tbm na nav e permitir que o usuário marque o aviso como lido)

Database:
users: ID, username, hash, country
registered-tasks: ID, user_id, title, description, date
recurrent-tasks: ID, user_id, title, description, recurrency, exceptions
recurrent-tasks-deleted: recurrent_task_id, user_id
